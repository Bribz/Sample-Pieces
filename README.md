# Sample-Pieces
Portfolio of sample code snippets for show.
Collection of small samples of previous work, with permission granted to showcase.

## Ability System
A simple system for creating, attaching, and triggering Traits in an action-forward game. 

These traits are broken down into two components: Strategies and Effects. Strategies represent the particular thing that needs to be accomplished to get some sort of Effect. 
The given sample pieces represent a Reload effect that could be granted via a Check-For-Movement strategy.

## Input and Managers
Sample pieces of Unity-based input management and game state management, pulled from a small client-server project.


## ProcGen Animation
A few example pieces of procedurally generated animation, and the components used to accomplish it. 
Includes a scripted bird rig, as well as a jiggle constraint for example use.
